# 🛒 MERN E-Commerce

A full-stack E-Commerce web application built using the **MERN Stack (MongoDB, Express.js, React.js, and Node.js)**. This project provides a seamless shopping experience with secure user authentication and a modern, responsive interface.

> 🚧 **Project Status:** Currently under development. Core functionalities have been implemented, and additional e-commerce features are actively being added.

## ⚙️ Installation

### Clone the Repository

```bash
git clone https://github.com/jyotsana305/MERN_ECommerce.git
```

### Navigate to the Project

```bash
cd MERN_ECommerce
```

### Install Dependencies

```bash
npm install
```

### Configure Environment Variables

Create a `.env` file inside the backend folder and add:

```env
PORT=5000
MONGO_URI=Your_MongoDB_URI
JWT_SECRET=Your_JWT_Secret
```

### Run the Project

```bash
npm start
```

or

```bash
npm run dev
```
